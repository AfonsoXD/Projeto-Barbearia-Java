# 💈 Sistema de Barbearia

Sistema de gerenciamento de uma barbearia desenvolvido em Java utilizando Programação Orientada a Objetos (POO).

## 🚀 Funcionalidades

- **Clientes**:
  - Cadastro de clientes
  - Listagem de clientes
  - Busca de clientes (por ID ou Nome)
  - Edição de clientes
  - Remoção de clientes (com validação para impedir remoção de cliente com agendamento ativo)

- **Agendamentos**:
  - Cadastro de agendamentos (com validação para impedir horários duplicados)
  - Listagem de agendamentos
  - Busca de agendamentos
  - Edição de agendamentos
  - Cancelamento de agendamentos

## 🛠️ Tecnologias e Conceitos

- Java SE
- Programação Orientada a Objetos (POO)
- Encapsulamento, Construtores, Getters e Setters
- Coleções com `ArrayList`
- Validações de regra de negócio

## 💻 Como Executar

1. Compile os arquivos de código-fonte:
```bash
javac *.java
```

2. Execute o sistema:
```bash
java Main
```
